# Полное руководство и правила оформления документов Markdown

## 1. Заголовки (Headings)

```
# Заголовок 1 уровня (H1 — обычно название документа)
## Заголовок 2 уровня (H2 — основные разделы)
### Заголовок 3 уровня (H3 — подразделы)
#### Заголовок 4 уровня (H4)
##### Заголовок 5 уровня (H5)
###### Заголовок 6 уровня (H6)
```

---

## 2. Форматирование текста

* **Жирный текст:** `**текст**` или `__текст__` **жирный текст**
* *Курсив:* `*текст*` или `_текст_` *курсив*
* ***Жирный курсив:*** `***текст***` ***жирный курсив***
* ~~Зачеркнутый текст:~~ `~~текст~~` ~~зачеркнутый текст~~
* `Выделение кода (моноширинный)`: `` `код` `` `код`

---

## 3. Списки

### Нумерованные списки

```markdown
1. Первый элемент
2. Второй элемент
   1. Вложенный элемент 1.1
   2. Вложенный элемент 1.2
3. Третий элемент
```

### Маркированные списки
Для маркеров можно использовать дефис (`-`), звездочку (`*`) или плюс (`+`).

```markdown
- Первый элемент списка
- Второй элемент списка
  - Вложенный элемент
    - Глубокий уровень вложенности
- Третий элемент списка
```

---

## 4. Цитаты

Цитаты оформляются с помощью символа больше (`>`):

```markdown
> Это стандартная строка цитаты.
> Цитаты могут занимать несколько строк.
```

> Это стандартная строка цитаты.
> Цитаты могут занимать несколько строк.

## 5. Ссылки и изображения

### Ссылки
```markdown
[Текст ссылки](https://example.com "Всплывающая подсказка")
```
Пример: [Перейти в Яндекс](https://ya.ru "Поисковая система")

### Изображения
Синтаксис аналогичен ссылкам, но добавляется восклицательный знак в начале:
```markdown
![Альтернативный текст для доступности](https://via.placeholder.com/150 "Подпись к картинке")
```

## 6. Таблицы

Таблицы создаются с помощью вертикальных черт (`|`) и дефисов (`-`). Двоеточие (`:`) задает выравнивание текста в колонке.

| Выравнивание по левому краю | По центру | По правому краю |
| :--- | :---: | ---: |
| Ячейка 1 | Ячейка 2 | Ячейка 3 |
| Данные А | Данные Б | Данные В |

```markdown
| Выравнивание по левому краю | По центру | По правому краю |
| :--- | :---: | ---: |
| Ячейка 1 | Ячейка 2 | Ячейка 3 |
```

## 7. Блоки кода и подсветка синтаксиса

Блоки кода играют ключевую роль в технической документации. В Markdown они подразделяются на инлайн-код (внутристрочный) и многострочные блоки.

### 7.1. Многострочные блоки кода (Fenced Code Blocks)
Многострочные блоки оформляются с помощью тройных обратных кавычек (` ``` `) или тройных тильд (` ~~~ `) до и после блока.

Чтобы включить подсветку синтаксиса, сразу после открывающих кавычек укажите идентификатор языка программирования:

```python
def greet(name: str) -> str:
    """Приветствует пользователя."""
    return f"Привет, {name}!"

print(greet("Markdown"))
```

Примеры других языков:
* **JavaScript:** ```javascript
* **HTML/XML:** ```html
* **Bash/Shell:** ```bash

#### Блок без указания языка (простой текст)
```text
Простой текст или вывод консоли без подсветки.
```

### 7.3. Дополнительные возможности расширенных парсеров
Некоторые платформы (например, GitHub) поддерживают дополнительные фичи для блоков кода:
**Диаграммы Mermaid:** Позволяют создавать блок-схемы прямо в Markdown.

## 8. Горизонтальные линии

Разделители используются для визуального отделения крупных смысловых блоков. Создаются тремя или более звездочками, дефисами или подчеркиваниями на отдельной строке:

```markdown
---
***
___
```

## 9. Расширения GitHub Flavored Markdown (GFM)

### Чек-листы (Task Lists)
Удобно для управления задачами:
- [x] Изучить базовый синтаксис Markdown
- [x] Освоить таблицы и списки
- [ ] Написать собственный документ

```markdown
- [x] Выполненная задача
- [ ] Невыполненная задача
```

### Сноски (Footnotes)
Позволяют делать примечания в тексте[^1].

```markdown
Это текст с примечанием[^1].

[^1]: Текст сноски, который отобразится в самом низу документа.
```

[^1]: Текст сноски, который отобразится в самом низу документа.
